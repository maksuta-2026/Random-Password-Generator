## Описание программы 
*Приложение для генерации паролей с выбором длины и набора символов* --- 
## Требования для запуска 
- Python 3.8+
- Tkinter (обычно входит в стандартную поставку Python)
 --- 
## Как запустить 
python main.py 
##Как пользоваться 
- Ползунок для выбора длины (от 4 до 128).
- Чекбоксы для выбора наборов символов.
- Кнопка "Сгенерировать" — выводит пароль и сохраняет запись в истории.
- Кнопка "Копировать" — копирует пароль в буфер обмена.
- Таблица истории — отображает последние сгенерированные пароли (пароль, длина, набор символов, время).
- Сохранение истории в `history.json`. Можно вручную сохранить или загрузить историю из файла
##Проверки:
- Длина проверяется на указанном диапазоне.
- Нужен хотя бы один набор символов.
